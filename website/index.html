Everything a product team deploys

Apps from any Git host

GitHub, GitLab, Gitea, Bitbucket or a Docker image. Build with Nixpacks, a Dockerfile or buildpacks, and redeploy on every push.

  • GitHub
  • GitLab
  • Gitea
  • Bitbucket
  • Docker

Managed databases

PostgreSQL, MySQL, MariaDB, MongoDB, Redis and libSQL, with scheduled backups to S3 and restore from the dashboard.

Compose and Swarm stacks

Bring a compose file. LaunchForge adds domains, HTTPS and logs to it.

Domains and HTTPS

Let's Encrypt certificates are issued and renewed automatically. A hostname can belong to only one workspace.

Safe rollouts

A release takes traffic only after its containers pass health checks. Roll back to any earlier build.

Logs, metrics and alerts

Live logs, CPU and memory per container and per server, and alerts to Slack, Discord, Telegram or email.

Built for many teams on one server

Workspaces cannot see, reach or starve each other.

Private network per workspace
Services join their workspace's own network. Only the router is shared.
CPU and memory quotas
Limits apply when a service deploys, and usage is metered every minute.
Workload policy
Docker socket mounts, privileged containers and host namespaces are rejected.
Audit log and custom roles
Every change is recorded with who made it. Give people exactly the permissions they need.
Signed webhooks
Git deliveries are verified against the raw request body before anything builds.
Encrypted secrets
Credentials are encrypted at rest with AES-256-GCM.

From git push to live

  1. Connect a repository or pick a Docker image.

  2. Add a domain. HTTPS is issued automatically.

  3. Push. LaunchForge builds, checks health and switches traffic.

  4. Watch logs and metrics, or roll back in one click.

Install in one command

The installer sets up Docker Swarm, PostgreSQL, Traefik and the dashboard, then prints the address to open.

$ curl -fsSL https://raw.githubusercontent.com/Aayushajs/LaunchForge-OS/main/scripts/install.sh | sudo bash
✔ Docker 27.3 ready
✔ Swarm initialised
✔ PostgreSQL 16 healthy
✔ Traefik listening on 80 and 443
✔ Dashboard is healthy

  Open http://203.0.113.10:3000

$ sudo bash install.sh upgrade --version 0.3.0
