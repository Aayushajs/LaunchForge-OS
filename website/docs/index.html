LaunchForge documentation

LaunchForge is a self-hosted platform as a service. Give it a server and a Git repository: it builds the code into a container, runs it behind HTTPS on your domain, and gives you logs, metrics, databases, backups, rollbacks and team access from one dashboard.

curl -fsSL https://aayushajs.github.io/LaunchForge-OS/install.sh | sudo bash

  • ApplicationsAn application is one container, built from source or pulled as a prebuilt image.

  • Docker ComposeRun multi-container apps from a compose file, start from a template, and see what the workload policy allows.

  • Domains and HTTPSCustom domains with automatic Let's Encrypt certificates, path routing, redirects and ownership rules.
