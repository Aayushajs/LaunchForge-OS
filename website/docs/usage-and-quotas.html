Operate

Usage and quotas

What a workspace reserves and actually uses, and how the operator sets its limits.

What the page shows#

Settings → Usage & Quotas shows, for the current workspace:

  • Reserved memory and CPU: the sum of the services' limits, counting services without limits at the default, against the quota.
  • The number of applications and databases against the quota.
  • Hourly usage for the last 24 hours: average CPU, average and peak memory, and the number of containers. It is sampled every minute from the running containers and kept for 90 days.

How limits are enforced#

Limit Enforced when
Memory (MB), CPU Every deployment of an application or database. Services without limits get DEFAULT_SERVICE_MEMORY_MB (512) and DEFAULT_SERVICE_CPU (0.5).
Applications (including compose) Creating one
Databases Creating one
Domains Adding one

A deploy that would exceed the quota is refused with a message such as:

text
Memory quota exceeded: this service needs 512 MB but only 256 MB … is left

Lower the service's limits, stop or remove another service, or ask the operator for more.

Note

The memory and CPU quota covers services running on the platform's servers. A workspace that connects its own server under Settings → Remote Servers can run anything there without touching its quota.

For the platform operator#

In the platform workspace the same page lists all workspaces, with an editor for each one's limits. Leave a field empty for no limit. Quota changes are recorded in the audit log.

Workspaces created by public sign-up start with the sign-up quota:

Variable Default Meaning
SIGNUP_QUOTA_MEMORY_MB 1024 Memory that a workspace's services may reserve in total
SIGNUP_QUOTA_CPU 1 CPUs that a workspace's services may reserve in total
SIGNUP_QUOTA_APPLICATIONS 3 Applications per workspace
SIGNUP_QUOTA_DATABASES 2 Databases per workspace
SIGNUP_QUOTA_DOMAINS 5 Domains per workspace
DEFAULT_SERVICE_MEMORY_MB 512 Memory limit for a service that does not set one
DEFAULT_SERVICE_CPU 0.5 CPU limit for a service that does not set one

Choose values that fit your server. On a 24 GB machine, for example, 1 GB per user leaves room for about twenty active users. See Run a public platform.
